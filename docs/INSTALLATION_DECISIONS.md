# Решения по установке Qronion

## 8 ноября 2026 года: чистая переустановка на ВМ

Пользователь планирует разработать новый удобный установщик. Текущую очередь
на виртуальной машине предполагается удалить и установить заново.

Для перехода на Alembic выбрана чистая установка в пустую PostgreSQL-базу.
Автоматический перенос базы из старых версий без Alembic не требуется.
Новая версия не должна молча помечать старую структуру как актуальную.

Это решение позволяет менять внутреннее устройство проекта. Основное
требование: результат можно установить на ВМ. Новый интерфейс установщика
будет отдельной задачей. До его появления существующий установщик должен
копировать миграции и применять их до запуска приложения.

Этот документ фиксирует план, но не означает, что старая ВМ или её данные
уже удалены. Удаление и переустановка на ВМ здесь не выполнялись.

После первой установки через Alembic дальнейшие изменения структуры БД
оформляются отдельными миграциями с сохранением существующих данных.
